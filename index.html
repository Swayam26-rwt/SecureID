🔲 Multi-Scale LBP + Gabor Fusion

Local Binary Patterns computed at radii 1, 2, 3 capture micro-texture at multiple scales. A 4-orientation × 2-frequency Gabor filter bank adds frequency-selective texture sensitivity. Combined into a whitened cosine similarity space.

59-bin uniform LBP 8×8 spatial grid Gabor mean+variance Cosine metric

📈 Online PCA Whitening

Welford's incremental algorithm computes per-dimension mean and variance online. Each feature vector is standardized to zero-mean unit-variance — equivalent to PCA whitening — without storing a training set or computing an eigenvector decomposition.

Welford online Zero training data O(d) memory

🎯 Adaptive EER Threshold

Maintains a sliding window of genuine and impostor similarity scores. Sweeps 50 candidate thresholds to find the EER operating point (FAR ≈ FRR). Falls back to static threshold when fewer than 5 samples per class are available.

EER estimation 200-sample window 50-step sweep

🎬 Optical Flow + Multi-Scale Liveness

Passive liveness combines: multi-scale LBP entropy (printed photo detection), centroid optical flow arc curvature (replay vs genuine motion), bilateral symmetry score, and Laplacian-based texture sharpness. Attack type is classified with confidence score.

Optical flow arc Face symmetry Attack classification CLAHE equalization

🔀 Score-Level Fusion

Recognition and liveness scores are fused via weighted sum, geometric mean (weighted product), or min-pool. The fusion engine records outcomes and adapts weights using exponential moving average. ROC curve and EER are computed from session history.

Weighted sum Geometric fusion Adaptive weights ROC / EER

🔒 PBKDF2 + Cryptographic Audit

Templates are persisted with PBKDF2-HMAC-SHA256 (100k iterations) key derivation + random 16-byte salt per save. The audit log uses SHA-256 hash chaining: each entry's hash includes the previous entry's hash, making the chain tamper-evident.

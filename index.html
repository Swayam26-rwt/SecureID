Multi-Scale LBP + Gabor Fusion

ISO 19794-5 · Texture Descriptor

59-bin Uniform LBP across an 8×8 spatial grid (3776 dims) captures local texture topology. A 4-orientation × 2-frequency Gabor bank adds frequency-selective response. Multi-scale sampling at R∈{1,2,3} increases texture entropy discrimination for PAD.

59-bin uLBP 8×8 spatial grid 4θ × 2f Gabor 3776 + 16 dims

Online Welford Whitening

NIST 800-76 · Feature Normalisation

Welford's incremental algorithm maintains per-dimension μ and σ² in O(d) memory. Features are zero-mean unit-variance normalised dynamically: x̃ = (x−μ)/σ. Equivalent to PCA whitening without offline covariance decomposition. Initialises from first template.

Welford online O(d) memory Zero training data

Platt Sigmoid Calibration

NIST IR 8427 · Score Calibration

Raw cosine scores S_raw are mapped to posterior probabilities via P(genuine|S) = 1/(1+exp(A·S+B)). A, B are fitted via gradient descent on binary cross-entropy from session history. Falls back to isotonic (PAV) rescaling when samples < 10 per class.

Platt sigmoid Isotonic PAV fallback Log-loss objective 50-step GD

Mahalanobis Multi-Template Scoring

ISO 19795-1 · Intra-Class Variance

Given N enrolled BRTs, intra-class variance σ²_d is computed from pairwise score variance. The corrected match score S_corr = S_peak / (1 + β·σ_d) penalises inconsistent enrollment sets while rewarding stable multi-pose captures.

Centroid matching Intra-class σ² Consistency penalty β=1.5

Adaptive EMA Score Fusion

ISO 30107-3 §8 · Multi-Modal Fusion

CDS = w_BRS·P_rec + w_PAD·P_pad. Weights update via EMA: when BRS drives FNMR, w_PAD increases; when PAD drives FNMR, w_BRS increases. Also supports Geometric Mean (log-linear) and Min-Gate (strict-AND) fusion modes. Weights clamped to [0.30, 0.80].

Weighted sum Geometric mean Min-gate EMA α=0.08

Bayesian EER with Credible Intervals

ISO 19795-1 · Statistical Evaluation

Maintains a 200-sample sliding window of genuine/impostor scores. Sweeps 100 candidate thresholds to locate the Equal Error Rate operating point (FMR ≈ FNMR). Bayesian Beta posterior (Jeffreys prior α=β=0.5) provides 95% credible interval on EER.

Beta(0.5, 0.5) prior 95% CI 200-sample window 100-step sweep

Passive PAD Engine

ISO 30107-3 §6 · Attack Detection

Multi-signal PAD fuses: (1) Multi-scale LBP texture entropy across R∈{1,2,3}, (2) Optical-flow arc curvature via centroid trajectory, (3) Bilateral symmetry residual, (4) Laplacian texture sharpness. Challenge-response scored as information gain over uniform prior.

MS-LBP entropy Optical flow arc Bilateral symmetry Challenge IG

PBKDF2 + SHA-256 Audit Chain

FIPS 180-4 · FIPS 198-1 · Tamper-Evidence

Every authentication event is hashed with SHA-256 via the browser Web Crypto API. Each entry's hash includes the prior hash (H_i = SHA256(H_{i-1} ∥ Payload_i)), creating a blockchain-style tamper-evident chain. Chain integrity can be verified on-demand.

SHA-256 chaining Web Crypto API Chain verification

ROC / AUC Evaluation

ISO 19795-1 · Performance Benchmark

Receiver Operating Characteristic curve is computed from session history across 51 threshold candidates. Area Under the Curve (AUC) is estimated via trapezoidal integration. AUC = 1.0 represents perfect separation; AUC = 0.5 is chance-level performance.
